# EX30 Dash

Phone version of my EX30 driver display (same layout as the ESP32 screen).

**Open:** https://maxtand.github.io/EX30/ — in **Bluefy** for the Bluetooth OBD dongle, or in Safari for GPS/demo.

- **Demo** – simulated drive
- **GPS** – speed and distance from the phone
- **OBD** – Vgate iCar Pro BLE 4.0 via Web Bluetooth (Bluefy on iPhone). OBD-tools has a terminal, a scan of supported standard PIDs, and a table for EX30-specific PIDs.

Tap the strip to switch the consumption card between now / 1 min / 5 min.
